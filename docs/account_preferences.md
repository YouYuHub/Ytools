# 账号偏好设置

主题、强调色、会话状态显示、侧栏宽度及分组区展开状态按固定 `user_id` 保存。
聊天设置中的压缩、工具超时、重试、并发、子智能体、视频读取和语音语言，以及账号默认任务预算、工具确认模式也属于个人设置。
退出后重新登录、换浏览器或修改登录用户名，都保留这些设置。

入口仍是侧栏「设置」。主题和显示开关即时保存；聊天参数点击「确定」保存；语音语言自动保存。
工具确认模式只对已获执行授权的账号开放，不能用于提升账号权限。
模型密钥、供应商、实例模型配置、服务器安全配置及模型单价仍由管理员统一管理；会话自己的模型、工具、目录和标题设置继续随会话保存。

## 保存与同步

- 身份库 schema 7 的 `user_preferences` 表保存个人偏好，以账号 ID 为键，不依赖可修改的用户名。
- 服务端逐字段事务合并，多个页面保存不同字段不会覆盖彼此；同一字段以最后成功保存为准。
- 登录页面加载时先恢复服务端偏好再应用主题。仅迁移当前账号已有的浏览器缓存，不导入未隔离的共享旧键，也不覆盖已保存的账号偏好。
- 浏览器保留少量非敏感界面缓存及离线待同步值；恢复网络、重新聚焦页面或下次登录时重试。退出登录仍清除草稿等会话缓存，密码和验证码不会保存在这里。
- 未设置的聊天参数继承实例默认值；用户保存后写入自己的账号，不修改项目 `.env`。后台任务启动时读取所属账号的配置快照，修改用于后续任务。
- 完整备份包含个人偏好及其校验指纹，恢复时一起验证。

匿名登录页尚不知道账号，因此使用系统主题；进入已登录的聊天、文件编辑或账号页面后恢复账号主题。
