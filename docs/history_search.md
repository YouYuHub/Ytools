# 会话全文搜索

侧栏放大镜打开搜索弹窗，输入文字即可搜索全部已保存的会话，不受侧栏是否加载、分组是否展开影响。中文输入法组词期间暂停搜索，输入完成后防抖 280 ms；Enter 立即搜索，Esc、关闭按钮或背景关闭弹窗。

## 搜索内容与结果

- 标题、历史 JSONL 文件名、用户问题、助手回复、保存的思考、引用文字、工具参数与结果、错误、子智能体轨迹和压缩摘要。
- 每个命中的消息字段单列一条结果，同一会话可有多条；每条显示最多三个不同位置的片段，并高亮匹配文字。计数为命中的字段数，不是字符出现次数。
- 普通文字按子串匹配，不区分大小写；支持中文、单字、标点、换行。不会把输入解释为正则表达式或命令。
- 媒体可搜索已记录的名称/引用；不搜索图片像素、附件未写入记录的原始内容、base64、内部模型请求审计和远端协议状态。
- 搜索已落盘的完整记录，而不是供模型使用的压缩后上下文。正在生成且尚未保存的内容，要在落盘后搜索才能找到。

结果按会话的更新时间倒序排列，同一会话内按轮次和事件顺序排列。点击标题/文件名匹配打开会话；点击内容匹配定位对应轮次/事件，自动加载更早消息并展开思考、工具、子任务或压缩块。无法精确映射的旧记录退回该轮提问，记录已被编辑/删除则提示重新搜索。

## 后端接口

`GET /chat_history/search?q=搜索文本&limit=40&offset=0`

```json
{
  "query": "搜索文本",
  "results": [{
    "id": 123,
    "session_id": "yt-example",
    "filename": "yt-example_chat.jsonl",
    "title": "示例会话",
    "round_no": 2,
    "event_index": 1,
    "role": "assistant",
    "field": "content",
    "timestamp": "2026-10-14 12:00:00",
    "agent_id": "",
    "snippets": [{"text": "关于搜索文本的回答", "start": 2, "end": 6, "prefix": false, "suffix": false}]
  }],
  "total": 1,
  "session_count": 1,
  "offset": 0,
  "next_offset": null,
  "revision": "查询快照标识",
  "skipped_files": 0,
  "skipped_lines": 0
}
```

`round_no` 从1开始，`event_index` 是该轮 `events` 数组下标，从0开始；与前端历史解析口径一致。片段 `start/end` 按 Unicode 码点计数，前端处理 emoji 时用 `Array.from` 对齐。标题、文件名匹配的轮次为0。

下一页传 `offset=next_offset&revision=上一页revision`。会话变更、删除、重命名或查询文本变化导致快照失效时返回409；前端清空旧分页并重搜，避免分页错位。

## 性能、取消和容错

SQLite 缓存位于 `history_files/sidecars/history_search.sqlite3`，属于可重建的派生数据，不随会话导出。搜索读取原始 JSONL，不调用会改写历史的管理器方法。

此库仅用于会话搜索，与权限库 `history_files/state/permission_runtime.sqlite3` 独立。`documents` 表是可搜索文本单元，保存原文 `text`、用于大小写不敏感匹配的 `search_text` 及轮次/事件位置；每段文字保存两种形式，所以长会话、较多工具输出会增加缓存体积。删除该缓存后下次搜索会重新建立；不会丢失 JSONL 聊天历史或权限配置。更多目录与数据说明见 [本地数据存储说明](local_data_storage.md)。

每次搜索扫描顶层 JSONL 的文件状态，只重新解析大小/修改时间/文件身份发生变化的文件。删除会话会同时移除对应缓存。查询用 SQLite 的原生 `instr` 扫描规范化文字，只扫描一次，再为当前页读取正文；不依赖 OpenAI SDK、grep、rg 或 SQLite FTS 扩展。原始 JSONL 中可能有中文转义、整轮单行和媒体编码，因此不直接对文件运行 grep。

搜索在线程中执行，不占用聊天服务事件循环。前端同时使用 AbortController 和请求序号：输入一变化就使旧请求失效，关闭、清空、切换查询时取消请求，过期结果/错误不得覆盖新结果。后端检测断开后通过取消标记停止文件读取、等待锁和 SQLite 查询。首次建缓存也可取消，未提交的缓存会回滚，下次搜索重新同步。

缓存更新采用事务，分页包含查询快照。正在写入或无法读取的文件暂时跳过，避免返回该文件旧缓存中的误导结果；坏行不妨碍搜索其他完整记录，并返回跳过计数。网络失败/60秒超时可在弹窗重试。搜索片段使用文本节点渲染，历史中的 HTML/脚本不会在搜索结果中执行。
