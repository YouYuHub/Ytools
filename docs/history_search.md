# 会话全文搜索

展开侧栏或折叠图标栏的放大镜均可打开搜索弹窗，默认搜索未归档的已保存会话，可切换为已归档或全部会话，不受侧栏是否加载、分组是否展开影响。归档窗口可直接进入已归档内容搜索，普通入口重新打开时恢复未归档范围。中文输入法组词期间暂停搜索，输入完成后防抖 280 ms；Enter 立即搜索，Esc、关闭按钮或背景关闭弹窗。

## 搜索内容与结果

- 默认匹配会话标题、用户问题及主助手回答正文。代码和表格属于正文，照常匹配；不默认搜索保存的思考、引用独立记录、工具参数与结果、错误、子智能体轨迹/最终回复和压缩摘要。
- 勾选「包含工具与内部记录」可额外搜索上述内部记录；子智能体最终回复只有被主助手写入正文时才会在默认范围中匹配。
- 「匹配会话文件名」独立控制 JSONL 文件名匹配，默认关闭；无论是否勾选，结果卡片始终显示文件名。消息正文中已有的附件名称/引用仍作为消息内容的一部分匹配，不读取附件原始内容。
- 两个开关在当前页面关闭/重新打开搜索后保留，刷新页面恢复默认。切换范围会取消旧请求并从第一页重新搜索，不复用旧范围的计数和分页。
- 每个命中的消息字段单列一张结果卡片，同一会话可有多条；每张卡片始终显示会话标题、JSONL 文件名、轮次、记录类型及时间，滚动后无需回到分组开头确认归属。每条显示最多三个不同位置的片段，并高亮匹配文字；点击某个片段优先定位该片段。计数为命中的字段数，不是字符出现次数。
- 普通文字按子串匹配，不区分大小写；支持中文、单字、标点、换行。不会把输入解释为正则表达式或命令。
- 媒体可搜索已记录的名称/引用；不搜索图片像素、附件未写入记录的原始内容、base64、内部模型请求审计和远端协议状态。
- 搜索已落盘的完整记录，而不是供模型使用的压缩后上下文。正在生成且尚未保存的内容，要在落盘后搜索才能找到。

结果按会话的更新时间倒序排列，同一会话内按轮次和事件顺序排列。点击标题/文件名匹配打开会话；点击内容匹配定位对应轮次/事件，自动加载更早消息并展开思考、工具、子任务或压缩块。无法精确映射的旧记录退回该轮提问，记录已被编辑/删除则提示重新搜索。

子任务聚合后保留内部模型调用、工具调用/结果、最终回复对应的原始事件下标，避免重复关键词定位到同一子任务中错误的工具。定位先展开目标并测量实际布局，再滚动工具结果等内部滚动容器，最后瞬时对齐聊天区；支持跨 Markdown 行内节点的文字及片段上下文定位，并短暂高亮命中文字。旧浏览器不支持 CSS Highlights 时保留块级高亮。长会话后台回填按插入前后的锚点位移补偿，保持已有阅读位置，定位时取消过期置底操作。

## 后端接口

`GET /chat_history/search?q=搜索文本&limit=40&offset=0&include_internal=false&include_filenames=false&archive_scope=active`

`include_internal` 与 `include_filenames` 均为可选布尔值，默认 `false`。`archive_scope` 可选 active（未归档，默认）、archived（已归档）、all（全部）。筛选在读取变更文件和 SQLite 文字匹配前执行，命中总数、会话数及分页均基于筛选后的记录。

```json
{
  "query": "搜索文本",
  "include_internal": false,
  "include_filenames": false,
  "archive_scope": "active",
  "results": [{
    "id": 123,
    "session_id": "yt-example",
    "filename": "yt-example_chat.jsonl",
    "title": "示例会话",
    "round_no": 2,
    "event_index": 1,
    "role": "assistant",
    "field": "content",
    "timestamp": "2026-10-14 12:00:00",
    "agent_id": "",
    "snippets": [{"text": "关于搜索文本的回答", "start": 2, "end": 6, "prefix": false, "suffix": false}]
  }],
  "total": 1,
  "session_count": 1,
  "offset": 0,
  "next_offset": null,
  "revision": "查询快照标识",
  "skipped_files": 0,
  "skipped_lines": 0,
  "checked_files": 50,
  "indexed_files": 0,
  "excluded_files": 450
}
```

`round_no` 从1开始，`event_index` 是该轮 `events` 数组下标，从0开始；与前端历史解析口径一致。片段 `start/end` 按 Unicode 码点计数，前端处理 emoji 时用 `Array.from` 对齐。标题、文件名匹配的轮次为0。

下一页传 `offset=next_offset&revision=上一页revision`，同时保留两个范围参数。会话变更、删除、重命名、查询文本或范围变化导致快照失效时返回409；前端清空旧分页并重搜，避免分页错位。

## 性能、取消和容错

SQLite 缓存位于 `history_files/sidecars/history_search.sqlite3`，属于可重建的派生数据，不随会话导出。搜索读取原始 JSONL，不调用会改写历史的管理器方法。

此库仅用于会话搜索，与权限库 `history_files/state/permission_runtime.sqlite3` 独立。`documents` 表是可搜索文本单元，保存原文 `text`、用于大小写不敏感匹配的 `search_text` 及轮次/事件位置；每段文字保存两种形式，所以长会话、较多工具输出会增加缓存体积。删除该缓存后下次搜索会重新建立；不会丢失 JSONL 聊天历史或权限配置。更多目录与数据说明见 [本地数据存储说明](local_data_storage.md)。

每次搜索列举顶层 JSONL 文件名用于删除检测，只检查所选归档范围内的文件指纹和变更正文。查询先选择该范围内的会话，再通过文件索引定位其文档并用 SQLite 原生 `instr` 匹配规范化文字；现有缓存中即使保留了其他范围的全文，也不会参与本次文字匹配。之后只为当前页读取显示正文，不依赖 OpenAI SDK、grep、rg 或 SQLite FTS 扩展。原始 JSONL 中可能有中文转义、整轮单行和媒体编码，因此不直接对文件运行 grep。

为支持随时勾选扩展范围，缓存仍保留内部记录；缩小默认查询范围不会自动缩小现有 SQLite 文件。新增角色/字段索引使默认查询先筛选正文与标题，再匹配文字，减少对大段工具结果的扫描。已有缓存只需自动添加此索引，不需要重解析全部历史或修改 JSONL。

搜索在线程中执行，不占用聊天服务事件循环。前端同时使用 AbortController 和请求序号：输入一变化就使旧请求失效，关闭、清空、切换查询时取消请求，过期结果/错误不得覆盖新结果。后端检测断开后通过取消标记停止文件读取、等待锁和 SQLite 查询。首次建缓存也可取消，未提交的缓存会回滚，下次搜索重新同步。

缓存更新采用事务，分页包含查询快照。正在写入或无法读取的文件暂时跳过，避免返回该文件旧缓存中的误导结果；坏行不妨碍搜索其他完整记录，并返回跳过计数。网络失败/60秒超时可在弹窗重试。搜索片段使用文本节点渲染，历史中的 HTML/脚本不会在搜索结果中执行。
