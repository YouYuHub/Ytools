# 数据图表（```chart 代码块）

模型输出语言标签为小写 `chart` 的 JSON 代码块，前端渲染为「代码 / 图表」
双视图控件（与 svg/mermaid/canvas 同一套壳：代码/图片切换、缩放、全屏、
复制代码、复制图片）。渲染器为手写 SVG（`H5/src/chart.ts`），零依赖、离线可用。

## JSON 规范

```chart
{"type": "bar", "title": "单次请求费用（美元）", "xAxis": ["模型A", "模型B"], "series": [{"name": "费用", "data": [0.085, 0.022]}]}
```

| 字段 | 说明 |
|---|---|
| `type` | `bar`（柱状/直方图，分箱标签放 `xAxis`）/ `hbar`（横条，类目名长时用）/ `line`（折线，趋势）/ `pie`（饼图，占比）；`histogram` 是 `bar` 的别名 |
| `title` | 图表标题（可选） |
| `xAxis` | 类目数组（bar/hbar/line）；省略时按 `#1..#N` 生成 |
| `yLabel` | 数值轴单位（可选，仅 bar/line 显示） |
| `series` | `[{name, data}]`，`data` 与 `xAxis` 等长（短补 0、长截断）；多系列即分组对比 |
| `data` | 仅 pie 可用：`[{name, value}]` 简化形；也可用 `series[0].data` + `xAxis` |

## 容错与上限

- 非法 JSON / 未知类型 / 缺数据 → 图片视图显示错误说明，代码视图可复制修正重发；
- 非数字（及饼图负值）置 0 并在图注记警告；饼图全 0 视为无内容报错；
- 上限：类目 64（hbar 40）、系列 8、扇区 32，超限截断并注记；
- 类目/图例标签超 24 字截断（悬浮看全文）；类目 ≤12 时柱/条顶显示数值；
- 负值：bar/line/hbar 以 0 为基线双向绘制。

## 前端行为

- 未闭合栅栏按普通代码块显示，闭合后成图；渲染是 JSON 的纯函数，
  流式重建无状态可丢；
- 文字/坐标轴用 `currentColor` 跟随主题，数据色用固定色盲友好色板；
  SVG 内禁用 `var(--*)`（复制图片的隔离导出上下文解析不了）；
- 悬浮数据点/柱/扇区显示数值（原生 `<title>`）。
