# 输入框快捷命令

在消息输入框的第一个字符输入 `/`，会在输入框上方打开快捷菜单。继续输入英文命令名、中文名称或别名可筛选；使用 `↑`、`↓` 选择，`Enter` 或 `Tab` 执行，`Esc` 关闭。也可以直接点击菜单项。

选中命令后，已输入的 `/命令` 前缀会从草稿中移除，后续正文保留。命令本身不会发送给模型；没有匹配项时，输入框仍可作为普通消息使用。不可用的命令会显示原因，按 `Enter` 不会把该命令误发给模型。

| 命令 | 功能 |
| --- | --- |
| `/file` | 选择文件，添加到待发送附件 |
| `/tools` | 选择当前会话的工具 |
| `/skills` | 打开 Skills 提示词库，可将提示词加载到输入框 |
| `/model` | 打开模型与参数设置 |
| `/settings` | 打开聊天设置 |
| `/search` | 搜索历史会话 |
| `/compact` | 手动压缩当前会话，沿用原有二次确认 |
| `/share` | 导出当前会话与附件 |
| `/import` | 导入 JSONL 或 ZIP 会话 |
| `/new` | 开始新聊天 |
| `/workdir` | 编辑工作路径 |
| `/theme`（或 `/主题`） | 弹出主题选择，可切换跟随系统、浅色、深色；选择后立即保存 |
| `/terminal` | 查看当前会话的后台终端任务 |
| `/changes` | 查看当前会话的文件变更 |
| `/voice` | 启动语音输入 |
| `/stop` | 停止当前会话的生成或压缩 |

菜单复用现有功能入口和权限校验。`/compact`、`/share` 需要已有会话；`/terminal`、`/changes`、`/stop` 仅在对应任务或内容存在时可用。添加命令时，在 `H5/js/app/slash_commands.js` 的 `commands` 列表中配置名称、别名、可用条件和执行函数。
