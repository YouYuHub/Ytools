## 已有行为与本次未采纳项

- **视频能力警告**：之前的媒体配额修复已让已知 `mediaLimits.video=0` 返回明确跳过原因；未知供应商的明确数量错误可在无输出时裁剪请求并重试。该测试记录是在修复前产生的，不应重复添加另一套视频能力开关。网络视频的元数据为 null 是直链未下载探测的结果，不能据此判断模型能力。`vision=true` 同样不能证明视频受支持。
- **原生文档降级**：`auto` 已按 `supportDocTypes` 和服务端预算选择或回退文本；显式 `native` 保留错误及 `mode=text` 建议。PDF 页段与文本字符区间不是同一语义，静默降级容易让模型误以为仍在读取指定页段。供应商最终请求配额裁剪也不会自动执行解析器，详见 `media_limits.md`。
- **增量日志游标**：暂不加入字节偏移接口，避免编码边界和日志截断/重建引入额外状态；需要完整日志时使用已有 `read_file` 分页。尾部轮询用于观察最新进度，不保证覆盖轮询间全部输出。
- **标签探查新模式、完整 CSS、重定向链、第三搜索引擎及时效参数**：暂不扩展。`mode=html` 已可检查结构；新增引擎或时效参数需要实际可靠的数据源与验证，不能仅靠参数声明保证效果。DDG Lite 也无法保证绕过外部访问限制。
- **后台任务列表工具**：暂不增加模型可见工具；当前返回 job_id 和日志路径，足以管理本次启动的任务。若后续确实发生任务 ID 丢失，可另行设计按会话隔离的任务列表。
- **ask_user 超时默认回答**：不采用。用户未作答不等于接受某个选项，自动选默认值会改变暂停等待用户的交互语义。
- **todo_write 增量更新、子任务中间计划注入父模型**：保持完整计划提交和现有子任务事件展示，避免增量状态混淆与增加父模型上下文。报告并未证实存在对应功能故障。
- **search_files 文件名搜索/分组折叠、write_file 自动建目录提示**：当前内容搜索已按路径提供命中块，文件名可由终端检索；模型返回继续保持紧凑，暂不新增工具或展示状态。
