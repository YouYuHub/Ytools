# 上下文管理面板

入口：点击输入框上方的上下文用量、会话右上角菜单“上下文管理”，或输入 `/context`（中文别名“上下文”）。手机端可使用菜单和快捷命令。

## 展示内容

- **下一次请求预览**：当前已保存模型与接口模式、本地估算、聊天窗口、消息/系统提示/工具定义/文件清单占用。
- **压缩策略**：聊天与压缩模型的较小窗口、自动触发比例与阈值、历史目标和摘要预算。
- **活动摘要**：覆盖范围、文本预览、待重建状态。单块最多预览 6000 字符，最多展示 50 块，统计总数包含未展开的块。
- **历史轮次**：按最新到最旧分页，每页 40 轮，区分原文、已摘要、摘要加原文补充、待重建和当前运行轮次；标注进入问题索引的轮次。点击问题通过原有引用定位打开原文。
- **最近压缩记录**：最近 12 条事件的阶段、原因及已记录的前后体积；旧记录缺失的字段不自行推断。
- **Responses 远端状态**：有状态模式显示响应链、配置匹配、原生压缩窗口启用状态及最近完成响应的 usage。其他接口及 Responses 无状态模式说明其本地组装方式。

## 统计边界

这是已保存本地数据的预览，不是运行中 HTTP 请求转储。未发送草稿和附件、运行中尚未落盘的增量不包含在内；任务启动后的配置修改影响后续任务。

待重建摘要的占用不能代表重建后的请求大小。打开面板仅查看标记，不执行重建；下一次聊天或用户手动压缩时按既有流程修复。

Responses 本地摘要和远端响应链是两套视图。最近响应 usage 的时间点不等于下一次请求。仅在配置匹配、没有待启用压缩窗口且输出不含不透明压缩项时，用最近输入加输出提供“不含新增输入”的链体积参考；密文长度不用于计算 token。

轮次编号采用后端历史口径，与编辑、删除一致。同一轮可能包含多条用户注入消息，所以不一定等于提问导航中的用户消息序号。

## 操作与开销

打开和刷新仅执行读取，不请求模型、不发现或重启 MCP、不启动压缩。详细历史读取和 token 计算在工作线程执行，面板不增加后台轮询。

手动压缩复用原确认及流式处理；聊天设置、模型参数打开现有面板。从本地重新同步需确认，只对 Responses 有状态主会话提供，运行或待重建时禁用。切换会话关闭面板、取消请求并忽略迟到响应。

## 接口

复用 `GET /chat_context/token_stats`：

| 参数 | 含义 |
| --- | --- |
| `inspection=true` | 增加详细 `inspection` 对象 |
| `round_offset` | 从最新向旧的偏移，默认 0 |
| `round_limit` | 每页条数，默认 40，范围 1–100 |

工具估算沿用 `include_tools` 和重复的 `tool_names`。普通统计保持原结构；详细模式将 `round_tokens` 置为空，改用 `inspection.round_page.items` 分页，避免重复携带全部问题全文。

`inspection` 提供 `captured_at`、`model`、`policy`、`running`、`repair_required`、`repair_block_count`、`summary_blocks`、`round_page`、`recent_compactions`、`remote` 和 `notes`。不返回密钥、请求头、原始工具输出、原生 response 内容、响应 ID 或压缩密文。

未知会话返回原有 `exists:false` 零统计，不创建历史。详细模式使用临时只读管理器，不占长期缓存，不改写历史或执行崩溃恢复。

## 验证

后端 `test/test_context_inspection.py`：历史表示、补充轮次、分页、待重建、运行检查点、只读行为、工作线程、接口模式、配置变化及私有数据过滤。

前端 `H5/test_h5/context_panel.test.js`：入口、文本转义、无副作用读取、分页、跳转、迟到响应、失败重试、焦点恢复、操作守卫与同步确认。

浏览器使用隔离测试数据检查宽屏和手机布局、滚动、关闭、Escape 及控制台错误，不对真实会话执行写操作。
