# 可复用任务模板

## 入口

- 「＋ → 任务模板」，或在输入框开头输入 `/template`、`/模板`。
- Skills 提示词库中的「保存为任务模板」：将当前提示词正文与当前会话配置一起带入模板编辑器，核对后保存。

模板支持新建、编辑、保存、另存为副本、删除以及 JSON 导入导出。关闭面板会保留本页未保存的模板草稿；**刷新整个页面后，仅已保存的模板会保留**。

## 保存哪些内容

| 项目 | 含义 |
| --- | --- |
| 名称、用途说明 | 用于管理和选择模板 |
| 任务正文 | 将填入新会话输入框的任务描述 |
| 四种角色的模型 | 聊天、压缩、标题、子智能体的供应商和模型名称；未指定的角色使用全局默认模型 |
| 可用工具 | 沿用应用时当前会话 / 全局工具，或保存明确的工具集合；自定义后全部取消表示无工具模式 |
| 任务预算 | 沿用应用时当前会话 / 全局预算，或指定 tokens、费用、模型调用、工具派发、运行时间额度；0 表示该项无限制 |
| 工作路径规则 | 沿用当前会话 / 全局目录、固定绝对路径、或当前目录下的相对子目录 |
| 输出格式与验收要求 | 应用时添加到任务正文的两个独立小节 |

「从当前配置创建」会读取会话实际生效的模型引用、工具集合、预算与工作路径，并复制当前输入框文字。工作路径默认保存为固定路径，可手动切换为其他规则。不会自动保存会话历史或附件。

**模型生成参数、角色自定义请求头、API 地址与密钥不随模板打包。** 新任务按模型引用解析现有配置，参数和请求头沿用当前全局角色设置，模型的其余默认配置照常生效。需要不同的生成参数时，可在新会话的「参数」面板单独调整。模板不更改工具权限策略。

## 应用流程

1. 选择已保存的模板，或编辑一个新模板。
2. 点击「预览并新建会话」。后端检查模型、工具与工作目录，并展示实际配置及完整任务正文。
3. 核对模型、工具、预算、目录、正文后，点击「确认新建（不自动发送）」。
4. 系统建立**独立的新会话**，保存会话配置并填入任务草稿。确认文字、添加附件后，再点击发送开始运行。

应用不修改原会话，不停止原会话的后台任务；切换沿用现有草稿保存流程，保留原会话在当前页面的输入草稿。仅打开、编辑、保存和预览模板不会创建会话或调用模型、MCP 工具。

新会话在首次发送前刷新页面，仍可从会话元数据恢复初始任务正文。已有输入草稿优先；后台正在运行或已产生聊天轮次时不自动填回。初始草稿一旦被使用，之后删除全部轮次也不会恢复该正文。

Chat Completions、Messages、Responses 都使用项目已有的会话配置及预算执行链。模板不保存或复制 Responses 的远端会话 ID、响应链、本地历史和摘要，新任务从独立上下文开始。

## 路径、工具与预算规则

- 固定路径必须是已存在目录的绝对路径；相对子目录以应用时的当前会话目录为基准，没有当前会话时使用全局目录。不会自动创建目录，也不会更改全局工作目录。
- 相对子目录禁止绝对路径、盘符与 `..`，解析后也必须位于基准目录之内，避免符号链接等将路径指向外部。
- MCP 工具按「服务 ID + 工具原名」保存，应用时恢复为当前模型可见的调用名，避免跨服务重名和别名变更影响选择。
- 工具清单来自已有发现结果，不在预览时自动启动所有服务。未发现的工具会阻止应用，可以在模板的工具区域点击「刷新工具清单」重新发现，或更换工具。
- 模型移除、服务或工具失效、工作目录不存在都会明确报错，保留编辑内容，不静默删除配置。
- 与现有工具面板一致，非视觉聊天模型不能启用内置 `read_media`；预览时会提示更换模型或取消该工具。
- 沿用的工具、预算、工作路径会在确认新建时固化到新会话，不持续跟随原会话变化。未指定的模型角色也会将当时的全局角色配置写入新会话快照。
- 费用预算使用当前价格表的币种。自定义费用额度大于 0 时，模板币种必须与当前计价币种一致；可在预算区域明确修改，系统不自动换汇。价格表不保存在模板中。
- 验收要求以用户任务指令提供给模型，**不是自动运行的验证程序**。预算的到限暂停、追加额度和停止行为与普通任务一致。

## 可靠性与存储

模板保存在 `history_files/task_templates/templates.sqlite3`，已被项目现有的 `history_files/` Git 忽略规则覆盖。最多 200 个模板，每个完整定义不超过 256KB。导出的文件格式为：

```json
{
  "format": "ytools-task-template",
  "version": 1,
  "template": {
    "name": "代码审查",
    "description": "检查可靠性与性能",
    "prompt": "请检查当前项目并说明问题原因。",
    "models": {},
    "tools": null,
    "budget": {"tokens": 200000, "model_calls": 20},
    "budget_currency": "CNY",
    "work_dir": {"mode": "inherit", "path": ""},
    "output_format": "按严重程度列出问题、位置和修复建议。",
    "acceptance": "报告验证方法与测试结果。"
  }
}
```

导入先进行严格结构校验，只进入编辑草稿，不自动保存、创建会话或执行任务。模型引用里不接受 API Key、URL、请求头或启动命令等额外字段。**任务正文和路径仍可能包含业务信息，分享导出文件前请自行检查。**

保存和删除携带版本号；其他页面已修改时返回冲突，防止覆盖。可以重新选择模板加载最新版本，或将自己的草稿另存为副本。

预览结果带配置指纹；确认时配置若发生变化，会要求重新预览。新建请求使用 UUID 幂等标识，重复点击或网络重试返回同一会话，且不会重置该会话后来修改过的预算。会话写入失败会回滚预算写入；若进程在两个存储提交间退出，重试同一请求会补全预算，避免重复建会话。

## API

| 接口 | 用途 |
| --- | --- |
| `GET /task_templates` | 已保存模板摘要 |
| `GET /task_templates/options?source_session_id=...` | 可用模型、工具与当前配置捕获值，不启动 MCP 服务 |
| `POST /task_templates/validate` | 校验模板定义并补齐默认值，无保存副作用 |
| `POST /task_templates` | 保存新模板，正文为模板定义 |
| `GET /task_templates/{id}` | 读取完整定义、版本和时间 |
| `PUT /task_templates/{id}` | 更新，正文 `{template, version}` |
| `DELETE /task_templates/{id}?version=N` | 按版本删除 |
| `POST /task_templates/preview` | 正文 `{template, source_session_id}`，返回 `{summary, fingerprint}` |
| `POST /task_templates/start` | 额外携带 `request_id`（UUID）、`expected_fingerprint`，创建独立会话并返回 `{session_id, summary, reused}` |

请求参数错误返回 422，依赖或路径等业务校验失败返回 400，模板不存在返回 404，同名或版本冲突返回 409，存储错误返回 500。升级后重启后端并刷新前端生效。
