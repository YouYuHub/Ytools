# 浏览器语音输入

入口位于输入框右侧的麦克风。识别语言在「聊天设置 → 常规」顶部的「语音输入」区手动选择；桌面端标签与下拉框并排，手机端下拉框独占一行，使用系统原生选择界面。麦克风右下角的小角标显示当前语言（如中、EN、FR、日），悬停提示和无障碍名称包含完整语言名称。

提供 20 个语言/地区选项：普通话（中国大陆）、中文（台湾）、英语（美国/英国）、法语、德语、日语、韩语、西班牙语、葡萄牙语（巴西）、俄语、意大利语、阿拉伯语（沙特阿拉伯）、印地语、孟加拉语、乌尔都语、印尼语、越南语、泰语、土耳其语。默认普通话。没有自动语言检测，实际识别会把选定的 BCP 47 标签传给 `SpeechRecognition.lang`。

选择自动保存到项目 `.env` 的 `SPEECH_INPUT_LANGUAGE`（如 `en-US`），作为连接同一后端的所有浏览器、所有会话的默认识别语种；不改变界面语言。语种修改频率低，复用现有配置文件即可，无需使用 SQLite。清除浏览器网站数据、换浏览器或重启后端后，仍可从同一项目的 `.env` 恢复。它与聊天设置中需要「确定」的数值配置分开，取消弹窗不回滚已经保存成功的语言，恢复数值默认不重置它。

页面初始化和打开聊天设置时，通过 `GET /chat_config/speech_input` 同步；选择新语种时通过 `POST /chat_config/speech_input` 保存。保存期间禁用语言选择，防止并发写入乱序；迟到的初始化响应不得覆盖新选择。请求有 8 秒超时。后端写入失败或网络未确认成功时保留原选择、显示错误，可重新选择重试；若服务端写入成功但响应丢失，重新打开设置即可核对实际配置。

浏览器 `localStorage["ytools-speech-language"]` 仅保留离线缓存。后端配置不可用时沿用缓存，缓存也不可用时回退普通话；浏览器禁止存储不影响 `.env` 保存。首次升级且后端没有有效配置时，可把旧浏览器语种迁移一次（`only_if_unset=true`）；后端通过锁保证多个浏览器同时迁移时只有第一个生效，已有项目设置不会被旧缓存覆盖。已迁移标记为 `ytools-speech-language-migrated=1`。后端未配置或值不受支持时使用普通话，读取不会自动改写 `.env`。

多个页面不轮询语种变化：打开设置或刷新时获取最新默认值。后台同步获得新默认时，不打断当前听写，也不改变尚未提交的输入法/语音片段的处理规则；新语种从下次手动启动听写生效。仅识别语言持久保存，麦克风启停状态、浏览器授权和草稿不写入 `.env`，重启不会自动打开麦克风。

听写中切换语言会立即隔离旧实例，保留输入框草稿并取消尚未写入的输入法语音缓存。之后须再次点击麦克风，才会以新语言启动。编辑不停止听写；语音服务自然断开时尝试自动续听，网络、权限及设备错误则停止。旧实例迟到的结果和错误不影响新语言。浏览器不支持所选语言时会显示该语言的名称并停止，供用户手动选择其他语言，不静默回退为中文。

启动时先显示蓝色虚线等待态，收到浏览器的 `start`、`audiostart` 或有效结果后才转为红色录音态；30 秒内没有启动反馈则取消本次请求并明确提示。`stop()`/`abort()` 返回后仍可能在释放音频资源：用户立即重开时，先等待旧实例的 `end` 再兑现这一次点击；若浏览器不再发 `end`，2 秒后清理旧占用并尝试本次启动。等待期间再次点击、发送、切换语言/会话或隐藏页面会取消该请求，旧事件到达后不会迟到启动。同步启动抛错不会被当作占用资源，后续显式点击可重新启动。

`continuous=true` 允许单次连接产生多段结果，不承诺浏览器服务永不结束。服务自然断开时在约 300 毫秒后用新实例续听，以当前草稿和光标为起点；输入法提交期间等待提交完成。连续两次空白续听仍无文字，或启动、权限、设备、网络错误时停止并保留草稿，之后点击麦克风可继续。手动停止、发送、切换会话和隐藏页面不会后台续听。空 transcript 或 `nomatch` 会提示检查麦克风及识别语言，且不会用空字符串抹掉已经显示的草稿/临时文本；用户应区分识别服务没有返回文字与前端没有启动成功。

中文语音结果清理汉字间的多余水平空格；日语额外处理假名与汉字间的空格，插入时不人为拆开日文。其他语种保持识别结果内部的词间空格、标点及换行，包含法语标点空格、韩语分词和阿拉伯语/印地语等 Unicode 文本。所有处理仅作用于语音片段，不清洗手动输入的草稿。

键盘编辑继续复用当前识别实例。输入法组合期间只缓存结果，不软件改写 textarea 或干扰候选词；提交完成后按新草稿和光标接入新增语音，已显示、被手动修改或删除的旧片段不重放。语音服务改写已冻结的临时前缀时优先保留用户编辑，该条旧前缀修订不重新插入。手动停止、发送、切换会话或离开页面会隔离迟到事件及取消待写回缓存。

选项代表应用能够传递这些语言标签，不保证每个浏览器的识别服务都支持全部语种。语言及错误语义参考 [Web Speech API 规范](https://webaudio.github.io/web-speech-api/#speechreco-attributes)。测试使用模拟语音结果验证语言参数、文字处理、缓存和竞态；真实收音质量仍需使用目标浏览器和相应语言的音频验证。
