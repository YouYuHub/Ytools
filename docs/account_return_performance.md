# 从账号设置返回聊天的性能优化

原来“账号与安全”和聊天页是两个完整页面。返回会重新初始化界面、请求会话列表和历史、解析记录并重建聊天区；长会话下开销较明显。

现在从聊天页的设置菜单进入账号管理，会打开独立账号面板。聊天页面保留在内存中，关闭面板不重新加载会话，草稿、滚动位置、折叠状态及模型流保持原状。关闭后只轻量核对登录身份、显示名和账号偏好。浏览器后退关闭面板，前进可以重新打开；每次关闭都会销毁账号视图，清除其表单和临时敏感内容。

独立访问 `/ui/account.html`、使用修饰键在新标签打开、旧版后端或不支持原生 dialog 的浏览器仍使用普通页面跳转。部署后需要刷新已打开的聊天页一次。

## 安全边界

- iframe 仅加载现有的同源账号页，继续使用原有登录、MFA、CSRF 和权限检查。账号面板能力由服务端声明，旧后端不会误用新入口。
- 只有已认证的账号页带合法面板参数时允许同源嵌入；其他页面及匿名响应继续禁止嵌入，外站仍不能嵌入账号面板。
- 父子通信同时校验来源、窗口、固定账号 ID 和随机面板标识，不传递密码、验证码或密钥。
- 在面板退出登录、撤销当前设备或修改用户名，会同步使整个聊天窗口退出；账号变化不会被合并到旧账号的界面或缓存。

同时修正了历史区独立滚动会误关闭侧栏设置菜单的问题。只有真正移动菜单锚点的滚动才关闭菜单。

## 验证（2026-10-25）

隔离测试账号和 80 轮合成会话：原独立页面返回约 1757 ms，面板连续三次返回为 134 / 116 / 134 ms。后者没有聊天文档导航、历史文件请求或会话列表重载，原聊天节点、草稿和滚动位置保持一致。耗时是本机测试结果，实际耗时随设备和网络变化。

- Windows、Linux 账号与 HTTP 权限相关回归各 61 项通过。
- 前端全量 838 项通过；追加身份刷新校验后，身份与面板专项 20 项通过。
- 真实 Chromium 跨页面流程 17 项通过，覆盖长历史返回、运行中模型流、后退、改名、退出登录、账号隔离及独立账号页回退。
- 桌面和手机布局已截图检查；资源版本已更新。

测试记录和截图位于 `tmp/account-return-performance-20261025/`。

已在确认没有运行中模型任务后备份并启用。本机服务健康、104 个带版本资源校验及匿名账号面板拒绝访问通过；账号凭证、验证器、资源归属和实例 `.env` 保持一致，账号库版本仍为 7。
