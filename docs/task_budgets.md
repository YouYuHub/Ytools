# 任务预算与完整用量

入口：输入框「＋ → 任务预算与用量」、聊天设置常规页的预算按钮，以及顶栏用量统计。手机端可通过「＋」进入。

## 配置

每项预算分别选择「无限制」或「指定额度」：

| 项目 | 口径 |
| --- | --- |
| 累计 tokens | 本任务主模型、子任务、压缩和标题调用的输入与输出总量 |
| 预估费用 | 按调用时配置的模型单价估算，所有价格使用同一币种 |
| 模型调用次数 | 主、子及辅助模型共享，网络重新发起请求也计数；续取同一 Responses 响应不重复算新调用 |
| 工具派发次数 | 主、子任务共享；按派发调用 ID 去重，恢复时复用缓存结果不再计数 |
| 任务运行秒数 | 在调用边界检查，不计预算等待；主任务审批等待也从检查值中扣除 |

后端 `0` 表示无限制；默认所有项目均无限制。支持全局默认、当前会话独立配置，以及恢复跟随全局。新任务使用启动时的配置快照；修改默认设置不会暗中改变正在运行任务的额度。

费用单价单位是「每百万 tokens」，分别配置输入、输出和缓存读取价格。未填表示未知，免费模型需要明确填 `0`。存在用量记录后锁定币种，避免将不同币种直接相加；模型单价可以继续修改，历史调用保留原价格。供应商的缓存写入、阶梯价、折扣、税费等特殊收费不由这个简单估价器准确复现。

## 达到额度后

任一有限额度达到阈值后，后续模型请求或工具批次会等待。输入框上方显示预算提示，打开面板可：

1. 设定更大的**累计总额度**，继续原任务；界面会建议比当前消耗更高的值。
2. 仅将本任务改为全部无限制，继续原任务。
3. 停止任务。

继续操作绑定任务、会话和预算版本。旧页面的重复提交不能继续已结束或已换代的等待。继续直接解除后端等待，不会重新发送用户问题、重复请求已经完成的模型输出或重做已完成的工具。

这是调用边界限制，不能代替供应商的硬扣费额度。已经发出的请求或命令仍会完成；并发中的调用可能超过额度。工具批次整体放行，因此一个批次也可能跨过工具次数阈值。运行时间限制同样不会中途强杀正在执行的工具。后台命令继续由终端面板管理，预算停止不回滚已发生的文件或外部副作用。

启用费用额度却没有配置模型价格时，在发出该调用前等待。可先保存价格，再继续；如果之前已有未计价的调用，就应把本任务的费用限制改为无限制，或停止任务后重新规划。不能把未知费用当作免费。

子任务活动超时扣除预算等待。服务停止时沿用现有权限任务的挂起/检查点恢复；有可恢复检查点时先恢复原任务，再处理预算，不会绕过未知工具执行保护。

## 用量与显示

后端统一为 Chat Completions、Messages 和 Responses 记录调用。主模型、子任务、压缩（含原生 Responses 压缩）、标题分别归类，按任务和会话汇总。相同调用的累计 usage 帧更新快照，重复帧、刷新或 SSE 回放不会再加一次。不同请求即使供应商复用了响应 ID，也分别计数。

供应商未回传 usage、请求断开或仅返回部分数据时，不能得到准确账单。项目保留能取得的 usage，无 usage 时用输入和已输出文字估算，并明确标记估算/待返回；费用页显示已配置价格部分，未知单价单独计数。网络失败但没有账单信息的请求采用保守估算，可能高于实际扣费。

进程中断且未取到账单的调用保留估算或部分用量；跨重启恢复不自动核销这些未知消耗，因此可能高于供应商最终账单。

顶栏显示完整会话累计；本轮用量显示对应最新聊天任务的完整汇总，可悬停查看角色分类。预算面板显示各任务与角色明细，最多展开最近 30 项，累计值仍包含全部任务。编辑重发产生的新调用仍属于实际发生的消耗，旧任务计量不会因替换聊天文本被抹掉。

已有会话首次使用新功能时，以原主模型/压缩统计和历史子任务完成记录建立一次初始值；旧版本没有记录的标题用量和费用无法补算。原 JSONL 的 `usage_total` 保留兼容口径，新增完整统计由独立计量账本提供。

## 存储与接口

`history_files/state/task_costs.sqlite3` 保存预算、模型价格、历史初始值、任务状态、调用用量及工具派发 ID；不保存提示词、模型密钥或工具正文。SQLite WAL 与事务串行检查并发派发，主子任务共享同一额度。删除会话时同时清理其预算与计量。

计量库属于持久数据，应纳入完整备份。当前会话分享包不携带该库、预算控制状态或价格；导入会话保留原 JSONL 用量，后续任务按接收端预算计量。

| 方法 | 接口 | 功能 |
| --- | --- | --- |
| GET/POST | `/task_costs/config` | 读取/保存预算；会话 `limits:null` 恢复跟随全局 |
| POST | `/task_costs/pricing` | 保存全局币种和模型单价 |
| GET | `/task_costs/usage?session_id=...` | 会话和任务的权威累计快照 |
| POST | `/task_costs/{id}/continue` | 提交会话、预算版本及本任务新额度 |
| POST | `/task_costs/{id}/stop` | 停止该会话的指定任务 |

配置接口仅提供供应商和模型名称，不返回密钥或请求头。接口沿用项目现有的网络访问边界。

## 验证

`python -m pytest test/test_task_costs.py test/test_task_budget_integration.py -q`

`node --test H5/test_h5/task_costs.test.js`

覆盖配置、非法额度、主子并发、超限等待、追加额度、无限制继续、旧决定拒绝、工具去重、网络重试、三种协议统一计量、历史初始值、缓存价格、未知用量，以及前端刷新和跨会话过期响应。

轮次摘要由结构化用量与模型快照重新生成；“含估算/待返回用量”最多显示一次，最终用量返回后移除。旧摘要中已经堆积的重复提示会在刷新时清理。DOM 观察器只响应相关摘要变化，忽略自身写回和普通正文输出，避免重复追加与持续重绘。
