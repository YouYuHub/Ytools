# 侧边栏会话运行标记

实施日期：2026-10-23。

## 显示规则

- 会话标题右侧显示小型转圈，覆盖聊天生成、自动压缩和独立的手动压缩；未打开的后台会话同样可见。
- 本页实时连接收到等待确认、等待预算或正在停止事件时，使用静态标记；悬停或辅助阅读可获取状态说明。网络状态未知使用虚线标记，避免一直假装运行。
- 完成、停止或失败后清除标记。最近列表、分组及多选中同一个会话共用状态；隐藏输入框上方的主任务状态栏不影响本功能。
- 图标在标题按钮内部独立占位，三点菜单保留；遵循减少动态效果偏好，减少动态时不旋转。

## 状态同步

本地开始和收尾事件即时更新。后台状态通过一次批量快照恢复，不逐个查询所有会话：有已知活动任务时每 4 秒检查，无活动时每 12 秒检查，以发现其他页面启动的任务。

隐藏页面时暂停检查并取消在途状态请求，重新可见或获得焦点时补查；取消状态请求不影响后台生成。单次请求最多等待 8 秒，失败按 8/16/30 秒退避。失败时保留未知标记，成功确认后恢复运行或清除。后台快照只提供运行/压缩概况，精细阶段由本页实时连接提供。

请求合并，旧响应不能清除新任务或让已结束任务重新转圈。同阶段后续 token 不重复修改图标 DOM；列表重建直接使用当前缓存。

## 接口与职责

`GET /chat_stream/statuses` 无参数，响应禁止缓存，仅返回正在运行的会话，按 ID 排序：

```json
{"sessions":[{"session_id":"example","chat_running":true,"compacting":false}]}
```

汇总主进程流、会话 worker 代理及手动压缩任务。只读取现有注册表，不启动 worker、不读取或创建历史、不扫描整个会话目录。已结束、空闲、仅挂起等待恢复的旧任务不算运行中。

`H5/js/app/session_activity.js` 管理缓存、批量同步与图标；`task_status.js` 发布本地阶段；`sessions.js` 构建行时应用当前状态。旧后端返回 404 时停止批量检查，本地任务指示仍可使用，未知后台状态使用静态标记。
