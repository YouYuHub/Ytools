## 常用写法

- **角色设定**：你是一位严谨的代码评审专家……
- **任务步骤**：先列出计划，再逐步执行
- **输出要求**：用表格汇总结果，代码块标注语言

## 输出格式示例

| ---- | ---- | ---- |

| 2 | 编写方案 | 设计文档 |
| 3 | 实现与自测 | 可运行代码 |
