# 模型支持文件输入说明

| 供应商 | PDF | DOC/DOCX | PPT/PPTX | XLS/XLSX | 上传后如何给模型 | 是否保留文档视觉信息 |
|---|---:|---:|---:|---:|---|---|
| **OpenAI GPT** | ✅ | ✅ | ✅ | ✅ | `Responses API → input_file/file_id` | **PDF：✅**；Office：❌默认只提取文本 |
| **Anthropic Claude** | ✅ | ❌ | ❌ | ❌ | `Files API → file_id → document` | PDF：✅；Office 需自己转文本/PDF |
| **Google Gemini** | ✅ | ❌* | ❌* | ❌* | `Files API → URI → document` | **PDF：✅**；非 PDF Office 不属于其原生文档视觉链路 |
| **Kimi** | ✅ | ✅ | ✅ | ✅ | `Files API → 提取 Markdown → messages` | 主要是**内容提取**，不是 PPT 页面视觉输入 |
| **Qwen / 百炼** | ✅ | ✅ | ✅ | ✅ | `Qwen-Doc-Turbo / Qwen-Long → file_id/doc_url` | 取决于解析器；可使用视觉解析 |
| **DeepSeek** | ❌ | ❌ | ❌ | ❌ | 只能自己解析后传文本/图片 | 图片：✅；原始 Office：❌ |
| **Mistral** | ✅ | ✅ | ✅ | 部分 | `OCR API → 文档结构/文本` | OCR/结构解析为主，不等于 LLM 原生视觉 |
| **智谱 GLM** | △ | △ | △ | △ | 未见与 GPT `input_file` 等价的通用官方文档输入 API | 通常需要自己做文档解析/图片输入 |
