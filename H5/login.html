首次使用

请在服务器的项目目录创建管理员：

python scripts/manage_accounts.py init-admin --username admin

随后刷新此页。公开注册已关闭。

密码已验证，5 分钟内可直接重试验证码。

打开 Google Authenticator 或 Microsoft Authenticator 中的 Ytools 条目，输入当前动态码；已绑定后无需重复扫码。

设备丢失／无法使用验证器？

可使用另一台已绑定的验证器，或绑定时保存的一条未使用恢复码。

没有备用设备和恢复码时，请联系服务器管理员核验身份，在服务器项目目录执行：

python scripts/manage_accounts.py reset-mfa --username YOUR_ACCOUNT 使用与服务相同的 Python 环境和配置。恢复后用原密码登录并重新扫码；账号和聊天数据保留。仅有网页访问权限无法执行此命令。

添加／更换验证器

先验证当前动态码或恢复码，再生成新的二维码；本次已验证的密码无需重复输入。

添加后，新旧验证器都可登录。

无法使用当前验证器时，可填写恢复码；两者都丢失请联系服务器管理员恢复。

首次绑定：使用 Google Authenticator 或 Microsoft Authenticator 扫码，再输入 6 位动态码确认。
